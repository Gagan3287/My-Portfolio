## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Gagan3287/My-Portfolio.git
```

Go to the project folder

```bash
cd My-Portfolio
```

Install dependencies

```bash
pnpm install
```

Run the development server

```bash
pnpm dev
```

Open

```
http://localhost:3000
```
